Mock Media Server API Documentation

This is a simple mock media server API. Below are the available endpoints and their usage.

GET /api/media

Retrieve all media items.

Response: Array of media objects

GET /api/media/:id

Retrieve a specific media item by ID.

Response: Media object or 404 if not found

POST /api/media

Add a new media item.

Request body (JSON):

{
    "title": "Media title",
    "type": "image|video|audio",
    "path": "/path/to/media.ext"
}

Response: Success message or error

GET /media/:filename

Access media files directly (Bonus feature).
